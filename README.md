# Fintech-payment-Transaction-Analysis
# 💳 Payment Transaction Failure Analysis


### 📌 Project Overview
Analysis of 6 million+ payment transactions to identify 
fraud patterns, failure rates, and risk signals across 
different transaction types.

### 🔍 Key Findings
- Fraud is concentrated in TRANSFER and CASH-OUT transactions
- Fraudulent transactions have significantly higher average amounts
- Fraud activity peaks during off-peak hours
- Transaction amount is the strongest fraud signal

### 🛠️ Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Jupyter Notebook
- Power BI
- Excel

### 💡 Business Impact
These insights can help any Fintech bank:
- Reduce fraud exposure by focusing monitoring on high-risk transaction types
- Set smart amount-based alert thresholds
- Improve overnight automated monitoring
